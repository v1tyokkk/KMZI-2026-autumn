# Лабораторная работа №1. Вариант 11

AES-128-GCM на C++ без сторонних криптобиблиотек.

| Параметр | Значение |
|---|---|
| Алгоритм | AES-128 |
| p(x) в GF(2^8) | x^8 + x^6 + x^3 + x^2 + 1 (`0x14D`) |
| f(x) GHASH | x^128 + x^7 + x^2 + x + 1 |
| Constant-time | алгоритм Карацубы для умножения в GF(2^8) |

## Сборка

Все исходники лежат в этой папке.

```bash
make
./lab1
```

Или:

```bash
c++ -std=c++17 -O2 *.cpp -o lab1
./lab1
```

Шифрование произвольных данных (hex):

```bash
./lab1 encrypt 000102030405060708090a0b0c0d0e0f cafebabefacedbaddecaf888 00112233445566778899aabbccddeeff feedface
```
